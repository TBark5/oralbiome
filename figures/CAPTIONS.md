# Figure captions

All figures are 300 dpi PNGs generated by `python run_all.py` from the real
Guo et al. saliva dataset (healthy n = 16, periodontitis n = 18; replication
cohort T n = 17, TP n = 16). Every statement is associational: this is a
cross-sectional study, so no figure shows cause and effect.

| File | Caption |
|---|---|
| `00_data_quality.png` | Read depth per sample (44,786-73,730 reads) and rarefaction curves; most curves flatten early, but a subset of samples with far more observed features (up to 2,328) stands out as a data-quality concern. |
| `01_composition_phylum.png` | Phylum-level relative abundance per sample and per group; Proteobacteria make up a larger mean share in healthy saliva (43%) and Firmicutes in periodontitis saliva (30%), with visible person-to-person variation (* = flagged atypical sample). |
| `02_composition_genus.png` | Genus-level relative abundance (top 8 genera + Other); *Haemophilus*, *Streptococcus* and *Neisseria* dominate both groups, and the four flagged samples are almost entirely "Other". |
| `03_core_microbiome.png` | Prevalence of the most abundant core genera (detected in at least 90% of a group); 33 genera meet the core definition in healthy saliva versus 11 in periodontitis saliva, partly because three periodontitis samples are flagged atypical. |
| `04_alpha_diversity.png` | Alpha diversity at genus level after rarefaction; no metric differs after BH correction across the four metrics (Shannon p = 0.80; Pielou's evenness p = 0.037, q = 0.15, rank-biserial r = +0.42). |
| `05_pcoa.png` | PCoA of Bray-Curtis and Jaccard distances with 95% ellipses; Bray-Curtis composition differs by group (PERMANOVA R² = 0.082, p = 0.015) with borderline unequal spread (PERMDISP p = 0.065). |
| `06_nmds.png` | Non-metric MDS of the same distance matrices (stress 0.13 and 0.11), shown as a rank-based check that the PCoA pattern is not an artefact of the ordination method. |
| `07_distance_heatmap.png` | Pairwise Bray-Curtis dissimilarity, samples grouped by status and clustered within group; the flagged samples (H7, P7, P9, P18) are dissimilar to almost every other sample. |
| `08_volcano.png` | Per-genus Mann-Whitney tests on CLR abundance for 354 genera; 2 genera pass FDR 5% (72 have raw p < 0.05 versus 17.7 expected by chance, and label-shuffled data average 0.07 FDR hits). |
| `09_top_taxa_boxplots.png` | CLR abundance of the 8 genera with the smallest p-values; *Fretibacterium* and *Peptococcus* (known periodontitis-associated genera) tend to be higher in periodontitis, while several healthy-leaning genera are environmental taxa concentrated in a high-richness subset of healthy samples. |
| `10_red_complex_species.png` | Pre-declared test of the three red-complex species: *P. gingivalis* (q = 0.005), *T. forsythia* (q = 0.012) and *T. denticola* (q = 0.004) are all more abundant in periodontitis saliva. |
| `11_cooccurrence_network.png` | Spearman co-occurrence network on CLR genus abundances (\|rho\| >= 0.6, q < 0.05); hubs include *Campylobacter*, *Fusobacterium* and all three red-complex genera, which co-vary strongly with each other (rho 0.68-0.85). |
| `12_roc_curves.png` | Out-of-fold ROC curves from 10x repeated 5-fold CV with bootstrap 95% bands; L1 logistic regression reaches AUC 0.92 [0.81, 1.00] and random forest 0.81 [0.65, 0.94]. |
| `13_feature_importance.png` | Genera used by the classifiers across the 50 fold-level models; one unidentified taxon ("Unclassified Bacilli") is selected in every L1 fold, and dropping it lowers the AUC to 0.64 (L1) and 0.72 (random forest). |
| `14_permutation_null.png` | The same pipeline run on 100 label-shuffled datasets gives AUCs centred on 0.5; the observed AUCs exceed every shuffle (p = 0.0099, the minimum possible with 100 shuffles). |
| `15_replication_forest.png` | Effect sizes in the primary cohort (H vs P) and the hypertensive replication cohort (T vs TP); the red-complex species lean the same way but are not significant in the replication cohort, and there PERMANOVA (p = 0.40) and the classifier (AUC 0.48) show no signal. |
